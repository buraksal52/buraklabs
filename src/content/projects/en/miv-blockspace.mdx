## Problem

Transaction volume on a blockchain network does not always represent meaningful user activity. Spam-like behavior and low-value patterns can make network usage difficult to interpret.

## Analytical direction

MIV Blockspace was designed to inspect transaction activity, visualize blockspace usage and explore signals that may indicate spam-like behavior or anomalies.

The dashboard is the interpretation layer: it helps inspect network behavior rather than presenting an unqualified classification result.

## Project context

The project was developed in the Monad Blitz Istanbul v2 hackathon context in September 2026, with an emphasis on productization and presentation.
