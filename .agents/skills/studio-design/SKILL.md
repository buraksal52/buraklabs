# Studio design workflow
Read `docs/DESIGN_SYSTEM.md`, `docs/PRODUCT.md`, `docs/COMPONENTS.md` and applicable content. **Do not produce a generic AI-generated landing page.**
1. Inspect content and target visitor journey; note which claims/images are real vs missing.
2. Make 2–3 distinct compositions or a reviewed design proposal BEFORE writing a new page. Specify information hierarchy, grid, typography, token roles, mobile behavior and motion purpose.
3. Prefer editorial asymmetric compositions and authentic project media. Experimental hero must have a meaningful static fallback and reduced-motion mode.
4. Implement semantic layouts; no inert controls, fake counters, decorative charts purporting to show project data, random glows, repeating three-card grids or pseudo-code props.
5. Check 360/768/1440 widths, light/dark, EN/TR, focus, contrast, hover/touch, reduced motion, slow network, empty/error.
6. Compare rendered screenshot against approved target; enumerate differences and correct them.
**Evidence to report:** screenshot paths, viewport and theme matrix, contrast check method, content provenance, remaining uncertainty. No screenshot? State NOT VISUALLY VERIFIED.
