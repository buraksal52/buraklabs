# Content authoring workflow
Read `docs/CONTENT_MODEL.md`, `docs/PRODUCT.md`, `docs/I18N.md`.
1. Establish provenance of each fact, date, publication status, role, repo link, result and media asset.
2. Collect missing facts rather than generating plausible filler. Internal TODOs allowed; no public invented claims.
3. Create validated typed metadata, stable id/translationKey, correct locale and unique slug.
4. Case studies must explain real constraints, trade-offs, architecture and verified outcome; research items distinguish ongoing/submitted/accepted/published.
5. Provide accessible diagram captions/alt, readable code and licensed media. MDX is not a license to execute untrusted script.
6. Test schema, links, drafts exclusion, i18n counterpart and sitemap/search publication rules.
**Output:** changed entries + provenance checklist + unresolved facts. Reject unsupported superlatives or invented quantitative results.
